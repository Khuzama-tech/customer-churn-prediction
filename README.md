# Customer Churn Prediction
## Week 1: Exploratory Data Analysis 
### Dataset - Source: Telco Customer Churn (Kaggle) - Size: 7,043 customers, 21 features - Target: Predict customer churn (Yes/No)
### Key Findings Overall churn rate: Approximately 26.5% of customers have churned, while 73.5% remain with the company.
Contract type: Customers with month-to-month contracts are much more likely to churn than customers with one- or two-year contracts.
Tenure: Customers with shorter tenure show a higher likelihood of churn, while long-term customers are generally more loyal.
Internet service: Customers using Fiber Optic service have a relatively higher churn rate compared with other internet service types.
